## What It Is

Destiny 2 App Menu is a browser-delivered, trainer-style utility created for Destiny 2. Its organized interface provides quick access to gameplay modifiers and helper functions covering damage behavior, ammunition, visibility, recoil, movement, and repetitive farming actions.

The project uses HTML as its delivery format, allowing the menu to be opened directly or served from a lightweight static location. Its controls are arranged for use in both PvE and PvP scenarios, making it straightforward to switch options as needed.
